# 本地整剧与剧集上下架

短剧列表只提供整剧上架和下架，不再进入独立的“上架管理”页面。整剧上架前，必填剧目资料缺失时会列出缺项并引导到编辑页；计划集数未全部准备好或部分分集未就绪时会提示，确认后只上架已就绪分集。整剧下架保留每集各自的上下架状态。

剧集管理按每集显示上架检查、提醒和状态。缺少该集必填内容的下架分集，其复选框和上架按钮会禁用；已上架分集仍可选择下架。支持对当前页已选的合格分集批量上架或下架。单集上下架只修改该集状态，不会自动改变整剧状态；整剧状态只由短剧列表操作。每次上架在确认框复核，服务端执行时重新校验内容指纹、状态和必填条件。

必填剧目资料包括英文标题和简介、短剧封面、分类、计划总集数和有效计费配置。分集必填项包括集号未超出所选版本的计划总数、处理完成的视频、有效计费配置，以及适用的试看资源。演员、标签、分集封面和未就绪的其他计划集会作为提醒；整剧仍可上架已就绪的分集。

已上架内容可继续编辑待发布草稿；线上快照及媒体引用保持不变，确认上架后才切换。整剧下架或上架不会重置各集状态；分集上架或下架也不会自动切换整剧状态。上下架操作仍记录在服务端事件历史中。

当前是本地管理基础：暂没有定时下架、观众端播放、真实积分交易或播放会话。下架对新观看的限制、已开始观看不中断、积分不误扣仍需在观众端和交易阶段联调验证。后台预览不产生交易和统计。存储保留及媒体进程见 [本地媒体处理](local-media.md)。
