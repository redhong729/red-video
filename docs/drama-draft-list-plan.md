# 剧目草稿与列表实施计划

日期：2026-11-18  
状态：数据库、草稿 API、后台列表与新增/编辑页面已实施并完成本地验证；分类/标签管理、媒体、分集、审核与发布仍待后续阶段。

## 1. 目标和范围

在已登录的后台中新增“短剧管理”，完成剧目草稿从创建、保存、查询到再次编辑的闭环。依次实施数据库、API、后台页面和验收；不在本阶段实现分集、上传转码、审核、发布、上下架或统计。

## 2. 已确认的页面方向

- 左侧新增“短剧管理”菜单，点击进入短剧列表。
- 列表沿用此前确认的完整运营字段：封面、标题、ID、分类、标签、已上架/已上传/计划总集数、状态、付费策略、排序值、更新时间。
- 页面提供“新增短剧”按钮，进入独立新增页面；编辑也使用独立页面。选择独立页面是因为剧目资料包含多语言、演员和付费配置，后续还会扩展封面与分集管理。
- 分类使用“全部 + 各分类”切换，一次选择一个分类；标签支持多选，命中任意所选标签即可。分类与标签条件同时满足。
- 本阶段列表行只显示可用的“编辑”操作；分集管理、发布和统计等入口随功能实现后加入。首期无删除入口。

## 3. 列表和筛选

- 列表默认按更新时间倒序；每页默认 20 条，可选 20/50/100。返回列表时保留筛选、页码和排序。
- 按此前确认的规则支持标题部分匹配（英文不区分大小写）或剧目 ID 精确定位；状态筛选以及付费策略、更新时间等高级筛选沿用 [剧目列表规则](../requirements/pages/admin/02-drama-list.md)，不同筛选项组合时同时满足。
- 字段布局保留完整运营视图。本阶段真实可得的字段展示实际数据；未接入封面资源或分集相关能力的字段显示明确的未配置/暂不可用状态，不能把未知数量写成真实的 0。仅创建草稿，其他状态及其操作随相应阶段实现，不伪造审核、上下架或统计结果。
- 区分暂无短剧、筛选无结果、加载中和请求失败；失败时保留筛选条件并允许重试。
- 页面中英文界面文案沿用现有国际化方式。业务名称由后端按内容语言规则提供，前端不自行翻译。

分类和标签的数据结构及读取接口属于本阶段范围。由于维护页面、去重、停用/删除与多语言回退规则还未确认，不在本阶段假定这些规则已完成；本地联调用的数据应通过明确的初始化方式准备，不能静默插入看似真实的运营分类。没有分类或标签数据时，页面如实展示空状态。

## 4. 新增与编辑草稿

- 独立页面按既有 [剧目编辑规则](../requirements/pages/admin/03-drama-editor.md) 设计，支持维护标题/简介的内容语言、分类、标签、演员、计划总集数、付费配置、试看和排序等本阶段可保存的数据。封面上传及分集截帧接入媒体阶段，页面应明确尚未接入，不把占位图视为已上传封面。
- 保存草稿只要求至少一种语言的标题；未填的发布必备资料可以后补。发布要求的英文标题、英文简介、封面、分类等仍在后续发布校验中执行，不能把保存草稿误当作发布。
- 手动保存后留在当前页；切换后台 UI 或内容编辑语言保留未保存输入。离开时提示保存或放弃；保存失败保留输入。
- 剧级排序默认 0、非负；计划总集数填写时为正整数。默认试看 30 秒，可设 0 关闭。付费配置支持不完整草稿；配置完成时执行适用的服务端校验。
- “保存并管理分集”依赖后续阶段，本阶段不展示不可执行的操作。

## 5. 实施顺序

### 5.1 数据库

1. 根据草稿、列表和既有规则设计剧目稳定身份、可选字段、多语言内容、分类、标签、关联、演员及付费/试看配置。
2. 配置必要的唯一性、引用约束和索引，保留后续线上生效版本与待发布稿的扩展空间；不提前实现未确认的审核流转。
3. 使用新的 Prisma 迁移建立结构，不清空现有管理员、会话或业务数据；准备可选、明确的自动化测试数据方案。

### 5.2 API

1. 实现需要登录的草稿创建、详情、更新和列表查询，以及分类、标签选项读取。
2. 服务端执行草稿标题及字段校验；列表支持已确定的分类单选、标签多选任一命中、关键词、分页与适用筛选。
3. 对不存在、校验失败、未登录等情况返回明确状态；保存完成后持久化并更新列表，不绕过现有会话保护。

### 5.3 后台页面

1. 在现有左侧导航增加“短剧管理”，接入列表及独立新增/编辑页面。
2. 列表使用真实 API 和真实分类/标签选项，完成组合筛选、分页、返回保留状态及可用的编辑操作。
3. 完成草稿表单、保存与未保存变更提示，覆盖中英文 UI 及错误/空状态。

### 5.4 验收

- 可登录后进入短剧管理；未登录不能访问相关 API。
- 只填写一种语言的标题即可保存，刷新后列表可见并可重新编辑；缺标题或非法数值不能通过后端校验。
- 新增/编辑不改变其他短剧及已有账号数据；没有自动上架或发布。
- 分类单选、多标签任一命中及组合筛选正确；结果、空态、失败和分页符合规则。
- 列表仅提供本阶段已实现的编辑操作；缺失的封面和未接入的分集数量如实展示。
- 切换语言、保存失败或从编辑页返回列表时不意外丢失相应输入或筛选上下文。
