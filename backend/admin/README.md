# 后台管理页面

后台支持管理员登录、短剧资料与剧集管理、封面与视频上传、媒体处理、上架确认与上下架，以及焦点图/热门/榜单运营；视频数据统计仍未实现。登录后默认进入短剧管理。

先按 [数据库与 API 说明](../api/README.md) 准备数据库和依赖。启动后台时，在仓库根目录打开三个终端：

```sh
# 终端一：启动 API；代码或模型有变化时先执行 corepack pnpm api:build
corepack pnpm api:start
```

```sh
# 终端二：启动管理页面
corepack pnpm admin:dev
```

```sh
# 终端三：启动独立媒体处理进程
corepack pnpm media:worker
```

`admin:dev` 只启动页面，不会自动启动 API 或媒体处理进程。三个终端需要保持运行；API 默认使用 `127.0.0.1:4000`。首次初始化需先安装依赖、执行数据库迁移并构建 API，详见 API 说明。

打开 http://127.0.0.1:3001/ 并使用管理员账号登录。首次账号初始化及本机初始密码位置见 [管理员和会话](../api/README.md#管理员和会话)。开发服务器只监听本机，并将 `/api` 请求代理到 `http://127.0.0.1:4000`。`ADMIN_ORIGIN` 必须与浏览器实际访问的协议、主机和端口一致（默认 `http://127.0.0.1:3001`）。如果 API 使用其他端口，可在启动开发服务器时设置 `API_PROXY_TARGET`，例如：

```sh
API_PROXY_TARGET=http://127.0.0.1:4001 corepack pnpm admin:dev
```

构建检查使用 `corepack pnpm admin:build`。构建产物是静态文件；开发代理不包含在构建产物中，今后部署时需由同源服务器单独配置 `/api` 代理和访问控制。

## 短剧管理

登录后从左侧进入“短剧管理”，可新增或编辑草稿。草稿至少需要一个语言的标题，其他发布资料可以后补；保存不会发布。列表支持分类单选、标签平铺多选任一命中、标题或 ID 搜索、状态与高级筛选。编辑后返回会保留列表筛选条件。

从左侧“分类管理”和“标签管理”可新增、编辑多语言名称、启用或停用条目。停用后仍可按历史关联筛选剧目，未被剧目关联的条目才可删除。名称至少填写一种语言，同类同语言名称忽略首尾空格和英文字母大小写后不可重复。

登录后从左侧进入“首页运营”，可分别选择已上架且至少有一集已上架的短剧，并用上移/下移调整首页焦点图、热门剧集和榜单顺序；焦点图最多 10 部、热门最多 12 部、榜单最多 10 部。首次配置会以原焦点标签剧目和原首页排序作为初始内容。榜单当前为人工维护，前端不显示虚构热度趋势。

已上传数量由完成上传的不同剧集统计；已上架数量按剧集状态统计；统计等待后续阶段；未实现的数量不会显示为零。登录过期时，如保存失败，请在另一个标签页登录，再返回原页面重试，原输入会保留。

## 常见启动问题

如果 Vite 输出 `http proxy error: /api/auth/me` 和 `ECONNREFUSED 127.0.0.1:4000`，说明页面进程连接不到 API。先检查 API 终端是否运行；未运行时执行 `corepack pnpm api:start`，如果 API 启动失败再查看该终端的具体错误和 PostgreSQL 状态。未登录时 `/api/auth/me` 返回 HTTP 401 是正常的，表示代理与 API 已连通。

## 剧集管理

从短剧列表点击“剧集管理”，或在短剧编辑页点击“保存并管理剧集”。先设置计划总集数，再新增剧集条目：集号必须是正整数、同剧唯一且不能超过计划总集数；已有剧集后不能把计划总集数清空或改小到最大集号以下。

剧集可维护多语言标题、单集免费或积分覆盖，以及跟随剧级、自定义或关闭试看。自定义标题留空时，后端按请求语言返回默认标题。列表按集号升序展示，不支持拖动调整。列表展示剧集封面、可复制的剧集 ID 和当前上传媒体 ID；剧集行可直接选择封面、手动截帧或另行确认设为短剧封面，也可预览已处理视频、针对单集上传或替换视频。替换已有视频需要在上传清单中确认。新剧集默认下架。

目前可配置剧集、上传视频，并在检查必填项后确认上下架；观众端可浏览并播放已上架的免费分集。媒体处理需单独运行 `corepack pnpm media:worker`；定时下架、真实扣积分、付费解锁和统计尚未接入。上传和转码状态与已建条目数量分开，页面不会把已建条目当成已上传的视频。


## 批量上传与媒体处理

在剧集管理进入“批量上传”，确认文件与集号映射后提交；上传页显示当前短剧的上传进度，支持分片续传、处理进度、失败重试、取消及视频预览。不再提供独立“媒体任务”菜单或跨剧任务页；旧 `/media` 地址返回短剧列表。封面操作统一从剧集行进入，选择候选图后需点击“确认封面”保存，取消不会更改当前封面。默认限制及处理进程、续传和存储说明见 [本地媒体处理](../../docs/local-media.md)。


## 短剧封面

在短剧编辑页的“短剧封面”选择图片并确认上传，已保存的封面会显示在短剧列表；更换采用相同流程。新建短剧可先上传封面，保存草稿时自动关联；已有草稿可以直接上传或更换。支持 JPG、PNG、WebP，单图不超过 10 MiB，宽高均不超过 8192 像素。封面独立于剧目资料保存，不会替代剧目资料保存。也可在剧集行的“选择封面”窗口选择画面，明确确认“设为短剧封面”；此操作不会修改分集封面。


## 上下架

短剧列表提供整剧上架和下架；已上架短剧的草稿资料修改后，可从列表“发布资料更新”写入线上版本，现有分集上架状态保持不变。剧集管理逐集显示上架检查，并支持单集或当前页批量上下架。缺少必填项时上架操作会阻断；整剧必填资料缺失时，列表会引导到编辑页。操作范围、校验规则与本地限制见 [上下架说明](../../docs/local-publication.md)。
