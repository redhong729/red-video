# 角色与权限

状态：已确认后台需审核能力；是否拆独立审核角色及账号权限，留待页面逻辑细化。

## 1. 角色与职责

| 角色或职责 | 能力 | 当前边界 |
| --- | --- | --- |
| 观众 | 浏览上架内容、筛选、模糊搜索、查看详情、观看及添加主屏幕入口 | 免费观看路径免登录；积分解锁的账户归属待定 |
| 后台运营人员 | 维护剧目、分集、分类、标签、语言资料、发布/下架及定时任务，查看统计 | 管理权限需登录校验；资料语言维护方式待定 |
| 审核职责 | 按提交版本查看、线上对比、完整授权预览、定位意见及通过/未通过留痕 | 页面能力已确认；审批主体、分权、多级及状态流转仍待定 |
| 付费权益持有人 | 获得对应内容的观看权益 | 后期账户与权益体系细化，不因此获得后台权限 |

## 2. 权限与可用性规则

1. 观众不能执行上传、编辑、审核、上下架和统计管理操作。
2. 非公开资料及后台预览仅向获授权的管理人员提供。
3. 新观看入口遵守整剧和分集上下架与媒体可用性；发布校验须匹配本次对象版本的有效审核通过结果，结果产生和权限由完整审核流转定义。
4. 已开始观看时发生下架，不主动中断当前观看；重新打开时受下架规则限制。
5. 积分解锁不能绕过下架限制；因下架无法成立的当次操作不扣积分并提示。历史权益补偿另行确认。
6. 审核完整授权预览与发布页观看资格模拟分开，均不真实扣积分、发权益或计业务统计；模拟不代表真实解锁已启用。

角色拆分、谁可以审核、谁可以配置付费与定时任务，以及操作记录范围，下一阶段再确定。
