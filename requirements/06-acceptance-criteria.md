# 验收条件草案

版本：v0.5  
状态：业务验收规划，未开发或执行测试；明确标注的待细化条件不作为已承诺的性能或交互细节。

## 1. 后台与内容发布

| 对应功能 | 场景 | 预期结果 |
| --- | --- | --- |
| A-01 | 未授权访问管理，登录后操作，退出后再次操作 | 管理权限按已确认角色执行；具体角色拆分待定 |
| A-02、A-06 | 查看四种状态，新建剧目并存草稿 | 支持草稿/审核中/已上架/已下架筛选；完整承载本轮建剧字段 |
| A-02 | 任一语言标题已填，其他发布资料不完整时保存草稿；随后校验发布资料 | 可存草稿；发布必须补齐英文标题/简介、封面、分类、总集数及有效付费配置，演员/标签可选 |
| A-02 | 上传封面或使用分集截帧；维护演员、总集数和排序 | 支持两种封面来源；演员姓名列表及可选角色名；总集数不低于已有最大集号；排序默认 0、非负、大值优先 |
| A-02、A-06 | 已上架剧目保存资料或剧级策略修改，再进行发布 | 保存只更新待发布稿，线上版本与主状态不变；发布生效后替换，存在修改时有标识；审核中的提交内容只读 |
| A-02 | 手动保存、保存并管理分集、切换语言及离开未保存页面 | 保存留当前或成功后按所选入口跳分集；保留跨语言输入，离开有保存/放弃提示，不自动上下架或扣分 |
| A-03、A-09 | 当前剧批量选择文件，集号不明/重复/超计划、既有集号冲突或格式大小超限 | 映射先预览确认；冲突由运营改号/替换/移出，不静默覆盖；执行MP4/50个/1GB限制，不合规项单独提示、其余有效项可继续 |
| A-03、A-09 | 上传成功、后台处理、候选/手动截帧 | 自动检测转码并准备适用资源，不自动上架；单兼容MP4目标最高1080p且保持比例不放大；阶段状态真实，替换剧封面另确认 |
| A-09 | 网络中断、刷新/关闭、临时错误及不可处理素材 | 同一原文件可续传，传完后处理不依赖页面；临时错误最多额外自动重试2次，仍失败手动重试失败阶段；不可处理素材直接提示，保留成功结果 |
| A-09 | 查该剧全部批次、按批重试失败/取消未完成 | 筛选和范围正确；取消中与已取消按实际停止区分，不删除已完成或影响线上；旧版本/迟到结果不误覆盖新目标 |
| A-03 | 计划多集，仅部分集完成并通过发布条件 | 允许连载上架，不要求总集数全部上传 |
| A-03 | 按集号展示、重传同一分集，或手动整剧下架 | 集号及前 N 集免费范围不变；重传不重复计已上传；整剧下架不清零原单集上架数，不能据此误认当前仍可播 |
| A-04 | 为剧目关联分类和多个标签 | 一个分类，多标签；维护与删除按后续确认规则执行 |
| A-06、A-08、A-09 | 候选媒体未就绪、同版本有效审核通过缺失或积分/试看无效 | 对对应目标阻断并定位原因，不能用旧版本结果替代；审批结果产生及权限仍待完整流转 |
| A-08 | 审核列表、线上对比、完整授权预览及填写意见 | 对象版本平铺、筛选/同剧关联正确；意见定位字段/集号/时刻；预览不扣分、不发权益或入统计 |
| A-08 | 记录通过或未通过，切换对象版本及查看历史 | 未通过原因必填，通过意见可选；绑定版本/实际操作人/时间，历史可追查，旧结论不批准新稿，通过不自动上架；执行权限另定 |
| A-06 | 预览线上/候选、不同语言及未解锁/有效解锁资格 | 对应真实所选配置，免费与试看效果正确，预览不真实扣分/发权益/计统计，不代表交易已启用 |
| A-06 | 连载未齐、演员标签空，部分独立目标未就绪或共享依赖失败 | 可选合格独立目标明确部分发布并列排除原因；非阻断项仅提醒，共享阻断不能绕过，无关草稿不误挡 |
| A-05、A-06 | 首次/追加/修改稿/恢复，预检后目标改变或重复点击 | 明确对象版本与目标集，实际提交复核最新状态与依赖；重复请求无重复副作用，分项结果正确，失败不误报线上替换，不自动恢复所有下架集 |
| A-07 | 后台中英文切换，包含上传失败与表单提示 | 组件与业务 UI 一同切换，业务数据不被前端自动翻译 |
| A-10 | 整剧/单集设置、查看、修改、取消定时下架，切换 UI 语言 | 统一北京时间 Asia/Shanghai，明确标示时区，语言切换不改变执行时刻；执行误差和冲突待任务逻辑定义 |
| A-03、A-05 | 当前页批量分集上架或下架并翻页 | 逐集校验并反馈成功/跳过/失败；翻页清空选择，不自动加入批量定时或批量改价/试看 |
| A-03、A-05 | 新增分集、修改已上架分集或下架最后一个上架分集 | 新集默认下架且校验后手动上架；修改稿发布后替换线上；最后一集下架联动已上架整剧下架，恢复不自动恢复所有子集 |
| A-02、A-03、A-09 | 删除短剧或剧集，包含已上架/审核中内容或活动媒体任务 | 删除前二次确认；已上架对象先下架、审核中及上传/处理中任务阻止删除；允许删除后清理关联数据库记录和媒体文件，短剧 ID 从首页运营配置移除；剧集删除不自动调整计划总集数 |

## 2. 观众端、下架与语言

| 对应功能 | 场景 | 预期结果 |
| --- | --- | --- |
| A-05、F-01～F-04 | 上架、整剧下架及单集下架后重新查询或从旧链接打开 | 公开范围一致；整剧下架限制其分集新观看；某集下架不自动影响其他可播分集 |
| A-05、F-05 | 正在观看时内容被下架 | 不主动中断当前观看，包括按确认边界继续加载媒体 |
| A-05、F-05、F-08 | 下架后重新打开同一内容 | 提示视频下架，提供后续路径；与内容不存在区分 |
| F-02、F-03 | 使用分类、标签及模糊关键词查询 | 支持模糊匹配；具体字段、组合和相关性按页面确认规则验收 |
| F-01～F-05 | 从首页，经分类或搜索结果到详情与分集播放 | 页面路径完整，免费内容免登录可看，媒体与所选分集一致 |
| F-07、A-12 | 切换 UI 语言后查询列表、分类标签、搜索与详情 | 请求携带当前语言；业务字段展示后端返回结果，不在前端重新翻译或混用旧语言数据 |
| F-07、A-12 | 业务字段缺少当前语言 | 剧名/简介由后端回退英文；分类标签按后续统一规则显示；前端不伪造译文 |
| F-08 | 首页无内容、搜索无结果、网络失败、播放失败、不存在 | 覆盖相应空态与异常，提示和恢复操作按页面细化验收 |
| F-06 | iPhone Safari 手动添加；Android 浏览器原生确认、取消或不支持安装 | 已安装图标打开当前语言首页；iOS 步骤指引可见，浏览器安装必须由用户确认；未支持时不阻断浏览；生产站点使用 HTTPS |

“已开始观看”和“重新打开”的具体会话范围、刷新与切集的处理，先确定后再补充测试步骤；不能以只验证已缓存画面代替当前观看不中断的规则。

## 3. 积分与统计

| 对应功能 | 场景 | 预期结果 |
| --- | --- | --- |
| A-02、A-03、A-06 | 剧级策略、单集免费/积分和试看配置组合 | 单集计费覆盖优先，试看跟随/覆盖/关闭可区分；适用时长短于正片；保存修改稿不改变线上配置 |
| F-05、A-03 | 未解锁付费集试看结束，免费或有效解锁观看，单集显式关闭试看 | 试看本集开头 X 秒，到点提示解锁且不自动扣分；默认 30 秒与覆盖正确，0 关闭不误回退；免费/有效解锁完整播放；不能获得超出试看范围的正片 |
| A-02、A-03、M-03 | 剧级默认与单集覆盖、变更剧级价格 | 单集显式覆盖优先，未覆盖跟随；前 N 集按集号；已有有效解锁不重复/补扣，列表按集号升序 |
| M-03 | 积分解锁时发现内容下架 | 当次最终无净扣分，提示下架；不误发可观看权益 |
| M-03 | 解锁与下架并发、扣费途中失败 | 结果符合确认的成立时点与补偿规则；此处场景已纳入，细节待冻结 |
| A-11 | 查看播放量、解锁量、完播率 | 按确定的剧目/分集与时间口径计算，排除预览、失败解锁及不适用行为 |
| A-11 | 没有交易、统计未启用或暂无数据 | 区分未启用、暂无数据与真实零值，不用模拟数据冒充真实指标 |

实际扣积分与解锁的执行验收在交易阶段启用后开展。积分购买、支付重复通知、退款及广告验收仍在后期补齐，不由后台存在付费配置推导已经具备交易能力。
