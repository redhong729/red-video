# 非功能需求

状态：质量要求建议；量化目标未冻结。与业务可用性规则共同验收，不另行改变产品范围。

## 1. 移动端、语言与海外访问

- 手机端便于浏览、筛选、切集和播放；海外首发国家、其他 UI 语言与视频语言待定。
- 观众端多语言且英文优先，后台中英文；前端请求携带当前语言，业务数据由后端返回，语言不同的数据不能被错误混用。
- 文本长度、数字和时间格式适配已启用语言；剧名/简介英文发布必备，缺译由后端回退英文；分类标签等字段的语言回退继续统一。
- 主屏幕入口与播放在目标真机上验收；离线下载与播放不自动纳入。

## 2. 权限与状态一致性

- 后台上传、审核、发布、下架与定时配置须校验权限，不能只在界面隐藏入口。
- 剧目和分集上下架规则覆盖首页、分类、搜索、详情与新的观看入口，不设置额外外放开关。
- 下架后已开始观看不主动中断，其后续媒体加载与新打开需要有一致的业务边界；具体会话有效期待细化。
- 因下架拒绝的当次积分操作最终无净扣分，扣费与权益结果可核对；并发边界与补偿待确定。
- 原文件、后台预览与观众播放的访问范围分别明确，不承诺阻止所有下载或录屏。
- 付费试看必须限制可获取的内容范围，不能仅在界面暂停同时向无权益用户提供完整正片；不要求运营额外上传试看视频，具体受限资源处理方案后续设计。
- 已上架剧目和分集的修改稿不影响线上版本，发布生效后新观看使用新版本，既有观看不被强制切换；旧资源保留和恢复边界在媒体流程定义。
- 建议记录审核、上架、下架、定时任务、价格与媒体处理变更，支持追查。

## 3. 批量处理与定时可靠性

- 上传、转码、审核分别呈现状态，不能上传成功即视为发布完成。
- 批量任务允许部分成功，保留成功结果；重试不应重复创建已成功分集或错误覆盖其他集。
- 初始输入范围 MP4、50个/批、1GB/个，输出单个兼容 MP4、最高1080p、保持比例且不放大；实际编码支持、参数、容量和耗时实施验证。
- 支持分片续传，站内切页上传继续，从当前剧集管理返回上传页查看进度，刷新/关闭后重新选同一原文件续传；传完后的服务器处理独立于页面，不能把离开页面误判为服务端任务已停止。2026-11-19 已取消独立全局媒体任务入口。
- 临时错误最多额外自动重试2次，仍失败可手动重试失败阶段；损坏/不支持直接提示，保留成功结果。
- 每批可取消未完成项，先取消中、确认停止才已取消，不删除已完成素材或撤回线上；任务版本与迟到结果需要一致处理，具体机制后续设计。
- 发布前校验必须与实际发布目标版本及关联影响一致，旧预检/旧审核不能替代最新条件；部分发布不破坏共享配置与资源一致性，失败不误报已替换线上。
- 定时下架已明确整剧/单集、逐条设置、查看/修改/取消及北京时间 Asia/Shanghai；执行结果、误差、重复计划和手动冲突继续细化，不能显示成功却未生效。

## 4. 数据与异常体验

- 列表空态、搜索无结果、内容下架、不存在、请求失败与播放失败分别表达。
- 后台预览和测试操作不污染真实播放、解锁及完播指标；统计口径、延迟和去重待定义。
- 交易或指标未启用时如实说明，不以虚构值模拟真实业务结果。
