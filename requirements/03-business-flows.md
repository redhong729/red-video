# 核心业务流程

版本：v0.5  
状态：已确认的业务环节已纳入；流转细节按 [规则确认稿](08-first-release-business-rules.md) 与页面细化继续确定。

## 1. 建剧、处理与连载发布

1. 运营登录后台，按草稿/审核中/已上架/已下架查找剧目，或新增剧目。
2. 填写标题、封面、简介、一个分类、多个标签、演员、总集数、付费策略与排序，保存草稿。
3. 为当前剧批量选择 MP4，识别明确集号并确认清单，纠正冲突；首期每批最多50个、单文件不超过1GB，支持断点续传。
4. 文件传完自动检测、排队转码、准备封面和适用试看，分别查看阶段状态；候选/手动截帧可用，失败按已确认规则重试或换素材。
5. 发布前按本次版本和关联影响校验必备资料、数量、积分/试看、媒体就绪及同版本有效审核通过；阻断与提醒分开，并预览对应版本/语言/资格。
6. 上架后进入观众端；允许总集数尚未全部上传的短剧连载发布。追加分集仍按自己的处理与审核状态决定是否可上架。

新上传分集默认下架，满足审核、转码和发布条件后手动上架；分集页可对当前页批量上架或下架，逐项反馈成功/跳过/失败，翻页清空选择。

已上架剧目的资料与剧级策略修改存为待发布稿，线上版本不变，待发布流程生效后替换；主状态仍为已上架并显示修改标识。审核中的已提交内容只读，具体退回和重提规则由审核页确定。

上架是公开控制，不再额外开启“允许外放”；媒体成功或审核通过不自动上架。送审与处理的衔接、审批主体、退回/撤回/重提及主状态迁移仍留完整审核流转。B-06 已确认对象版本平铺、线上对比、完整授权预览和版本绑定的意见结论历史。

整剧共享条件通过后，合格的独立分集可经明确确认部分发布，列明排除项；共享配置与受影响资源的阻断不能靠排除依赖绕过。恢复明确选择本次剧目/分集目标，不自动恢复全部下架集。

## 2. 找剧与观看

首页 → 分类/标签或搜索输入 → 搜索/筛选结果 → 短剧详情与分集 → 观看。

搜索支持模糊匹配；分类和搜索结果只展示符合上架要求的内容。免费内容保持免登录观看，积分内容的实际解锁阶段及账户规则另行明确。无内容、无结果、网络失败、地址不存在、内容下架及播放失败均有对应状态。

## 3. 手动与定时下架

1. 运营对整剧或单集执行下架，或按已设定任务到时下架。
2. 新内容查询与新打开入口遵守下架结果；整剧下架优先于单集上架，其他正常分集不因某集下架而自动受影响。
3. 正在观看的用户不被主动中断。对当前观看后续加载的处理应与此一致，不能因每次获取媒体而错误中断。
4. 重新打开已下架内容，提示视频下架；下架与地址不存在分别处理。
5. 当次积分观看操作如因下架失败，不扣积分并提示；并发扣分与下架的边界、回滚补偿待细化。

对已上架整剧，最后一个上架分集也下架时整剧自动下架；新建草稿不触发。恢复需人工校验上架，不自动恢复已下架分集；手动整剧下架不重置原分集状态。

定时任务支持整剧和单集，可查看/修改/取消，统一北京时间 Asia/Shanghai，时间旁明确标注且不随 UI 语言切换。执行误差、冲突和失败处理继续在任务逻辑定义。刷新、切集、自动连播及当前观看会话边界继续在观看页细化。

## 4. 语言切换与内容数据

1. 前端 i18n 确定当前 UI 语言。
2. 请求列表、详情、分类标签和搜索时携带当前语言。
3. 后端提供该语言下的业务展示数据，前端直接展示剧名、简介、分类与标签等字段，不再本地翻译一遍。
4. 切换语言后更新 UI，并建议重新请求受语言影响的数据。剧名/简介英文发布必备，缺译由后端回退英文；分类标签等字段的维护与回退在对应页面继续统一。

## 5. 手机主屏幕入口

观众在「我的」页选择添加入口 → 支持安装的浏览器展示系统确认，iPhone 提供 Safari 添加步骤 → 用户确认后出现 RED Stories 图标 → 图标以当前界面语言打开首页。

网站名称、应用图标和首页启动地址已设置。此入口只安装网站快捷应用，不下载短剧；未安装浏览器支持或不满足条件时，按设备展示操作步骤或隐藏不可用的安装动作。正式站点需使用 HTTPS，离线播放仍不在范围内。

## 6. 积分交易流程规划

购买积分仍作为后期方向：账户识别 → 选择套餐 → 支付结果确认 → 积分入账。

观看解锁流程的阶段待确认，建议：内容可用性检查 → 明示积分价格与权益范围 → 用户确认 → 再次校验可用性并完成扣分/权益操作 → 播放。

因为下架被拒绝时，本次最终结果不得保留净扣分；已拥有有效解锁不重复或补扣已确认。历史购买补偿、支付退款与试看结束后的具体页面交互仍在对应阶段细化。

已确认的试看路径：未解锁付费集播放正片开头 X 秒 → 到点停止并提示解锁，不自动扣积分；免费/有效解锁播放完整内容。剧级默认 30 秒可设 0 关闭，单集可覆盖，适用的试看短于正片；试看修改稿发布后生效，旧观看不强制切换。具体观看页交互和真实交易启用仍待对应阶段。

## 7. 统计与广告

统计范围已包含播放量、解锁量和完播率，后台预览排除已确认。其他有效行为、去重、时间范围和更新延迟，在统计页继续细化。

广告仍为后期方向。具体地区、广告形态、失败回退和是否观看广告解锁均未确认。
