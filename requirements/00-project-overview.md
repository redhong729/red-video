版本：v0.5 需求分析稿  
日期：2026-11-18  
状态：B-02～B-05 基础逻辑、B-06 工作台/记录及 B-07 基础校验/预览已确认；完整审核流转、真实交易启用、统计口径及其他页面继续细化。

## 1. 项目目标

建设以海外观众为主的短剧平台，一部短剧包含多集，支持连载、分类标签与模糊搜索。后台管理内容、分集、审核转码、上下架及视频数据；观众在前端找剧和观看，并可添加手机主屏幕入口。观众端界面多语言且英文优先，后台先支持中英文。

先本地开发；当前阶段继续整理产品规则与页面清单，不初始化工程。技术职责见 [技术方案](../docs/technical-plan.md)，具体工具版本见 [版本基线](../docs/technology-versions.md)。

## 3. 核心路径

后台：建剧/草稿 → 上传分集 → 审核与转码处理 → 预览、校验与上架 → 持续追加连载分集 → 上下架及定时管理 → 数据查看。

前台：首页 → 分类/标签或模糊搜索 → 结果 → 详情 → 分集观看；覆盖下架、无结果、网络与播放错误等状态。

审核与转码的先后关系、审核通过后的发布方式及部分状态迁移尚未确认，不以该路径代替详细流程定义。

## 5. 术语与边界

- 剧目包含多集视频；总集数是计划信息，不要求全部上传后才发布。
- 上下架控制新访问的公开范围；“允许外放”不再是独立开关。下架不强制打断已经开始的观看。
- 免费/积分付费与上下架分别判断，上架不等于免费。
- 后台中英文 UI、观众端 UI 与业务内容语言分别维护。发布必备英文标题和简介，其他语言按需维护，缺译由后端回退英文；分类标签的维护与回退后续统一，前端不临时翻译业务数据。
- 审核、转码及生命周期是不同维度，不能相互代替。
