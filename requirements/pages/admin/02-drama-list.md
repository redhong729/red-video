## 1. 页面目的与公共规则

后台运营人员查找剧目、查看状态和分集概况，进入新增、编辑、分集、预览/发布及统计，并执行整剧下架、批量下架和逐条定时下架。

沿用 [公共规则](../../08-first-release-business-rules.md)：四种主状态、一剧一个分类、多标签、允许连载、仅以上下架控制公开、下架不主动中断已有观看。没有独立外放开关。

## 2. 已确认选择

| 编号 | 用户选择 |
| --- | --- |
| LIST-Q1 | 完整运营列表；演员、简介和统计放详情/统计页 |
| LIST-Q2 | 默认最近更新时间倒序；不据此改变前台排序 |
| LIST-Q3 | 首期批量下架，定时下架先逐条设置 |
| LIST-Q4 | 全部和四状态页签；标题部分匹配且英文大小写不敏感、ID 精确定位；单分类、多标签任一命中；其他条件同时满足；高级筛选含付费策略和更新时间 |
| LIST-Q5 | 只选择当前页，翻页清空选择；提交前显示数量和影响，结果区分成功、跳过、失败 |
| LIST-Q6 | 默认每页 20 条，可选 20/50/100；返回保留条件、页码和排序；提供所列行入口；下架前确认；排序值到编辑页修改 |
| LIST-Q7 | 2026-11-23 用户要求短剧管理提供删除按钮；删除限制与影响见下方当前实现边界 |

## 3. 筛选逻辑

| 筛选项 | 已确认规则 |
| --- | --- |
| 状态 | 全部、草稿、审核中、已上架、已下架 |
| 关键词 | 标题按关键词部分匹配，英文不区分大小写；剧目 ID 精确查找 |
| 分类 | 选择一个分类 |
| 标签 | 可选多个，命中任意一个所选标签即可 |
| 高级筛选 | 付费策略、更新时间范围，作为折叠高级条件 |
| 条件组合 | 关键词、分类、标签组、状态及已使用的高级条件同时满足 |

默认“全部”、提交条件后查询、重置条件及切换筛选回第一页作为本页常规交互建议，列入下方默认约定；其界面位置在设计阶段落实。后台搜索范围已确认，不自动扩展前台搜索范围。付费策略筛选随 B-03 采用默认免费/按集积分，未完成配置的草稿需有明确说明。

## 4. 已确认表格信息

| 信息 | 说明与依赖 |
| --- | --- |
| 封面、标题、ID | 可识别封面尚未补齐的草稿，ID 稳定定位 |
| 分类、标签 | 一分类、多标签，较多标签的视觉折叠方式后续设计 |
| 已上架集数 / 已上传集数 / 总集数 | 依次为单集上架状态数、上传成功的不同分集数、计划总数；重传不重复计，整剧下架不清零单集上架数；是否当前可播另看整剧与媒体条件 |
| 剧目状态 | 草稿 / 审核中 / 已上架 / 已下架；已上架存在待发布稿时增加未发布修改标识，不改变主状态 |
| 付费策略 | 显示剧级默认免费或按集积分概要；单集显式覆盖优先，不能由剧级默认免费推断所有分集免费 |
| 排序值 | 默认 0、非负整数、大值优先，到 B-03 修改，不在列表行内编辑；前台使用位置另定 |
| 更新时间 | 默认倒序；哪些内容变更更新此时间随编辑及分集逻辑回填 |
| 操作 | 编辑、分集管理、预览/发布、统计及适用的上下架入口 |

演员、长简介和业务统计不增加到默认表格。上传/转码失败数量等额外提示如后续需要，单独补充，不能视作已确认列。

## 5. 操作入口

| 操作 | 去向或规则 |
| --- | --- |
| 新增 | B-03 新建模式 |
| 编辑 | B-03 编辑模式；审核中的提交内容只读，已上架修改另存待发布稿，线上版本保持不变 |
| 分集管理 | B-04，带当前剧目上下文 |
| 预览/发布 | B-07，按审核与发布校验规则执行，不在本页直接绕过校验上架 |
| 统计 | B-10，预选当前剧目，不在本页定义计算公式 |
| 整剧下架 | 下架前确认对象与影响，遵守已有观看保护和新打开限制 |
| 定时下架 | 首期逐条设置；时区、任务修改取消及冲突在定时逻辑细化 |
| 删除短剧 | 草稿或已下架时可发起；二次确认后永久删除整剧、剧集、关联上传媒体和发布记录，并清理首页运营引用；活动媒体任务时阻止。上架中或审核中不可删除 |

### 删除操作（当前实现边界）

用户要求增加删除按钮；以下状态限制和级联影响是当前实现的安全边界，并非另行确认的产品决策：上架中的短剧需先下架，审核中的短剧不可删除；有上传或媒体处理任务时需等待完成或取消。确认后短剧及其全部剧集、媒体文件、发布/上下架记录会被永久删除；首页运营配置会同步移除该短剧 ID。

## 6. 批量下架

- 只操作当前页手动选中的剧目，不保留跨页选择；翻页清空选择。
- 提交前显示数量与下架影响，执行时读取最新状态，检查可操作性。
- 结果分别显示成功、跳过和失败，不以部分成功冒充全部成功；已下架或其他不可操作状态按确认的结果分类说明。
- 不将批量上架或批量定时下架随本功能自动加入。
- 不主动打断已有观看；新打开受整剧下架限制。

筛选变化、重新查询或离开页面时建议清空选择，防止旧选择与新结果混用；这是常规交互建议，不扩展已确认的选择范围。

## 7. 分页、默认交互与返回

已确认每页 20 条，可切换 20/50/100；从编辑、分集、预览和统计返回时保留筛选、页码与排序。

常规约定建议：默认全部状态；查询/重置及切换条件后回第一页；相同更新时间采用稳定次序；返回后刷新当前数据；失败保留条件并允许重试。具体视觉、列宽和提示文案在设计时确定，不阻塞进入下一页。

## 8. 状态与语言

| 场景 | 处理方向 |
| --- | --- |
| 平台没有剧目 | 暂无内容，提供新增入口 |
| 筛选无结果 | 无匹配结果，可调整或重置条件 |
| 首次加载/翻页 | 给出对应加载反馈 |
| 请求失败 | 保留条件并允许重试，不作为空列表 |
| 剧目状态被其他操作改变 | 刷新状态，说明本次操作的最新结果 |
| 登录失效/权限不足 | 按后台公共访问规则处理，不混同于无数据 |

中英文覆盖表头、状态、操作和异常 UI。业务标题、分类标签按后端内容语言规则返回，不在列表自行翻译。

## 9. 验收重点与后续回填

1. 完整运营字段出现，缺封面等草稿仍能识别；默认最近更新在前。
2. 四种状态、标题部分匹配/ID 定位、单分类、多标签任一命中和组合条件正确。
3. 高级筛选按对应策略及时间规则工作，查询与清除不改变剧目本身。
4. 当前页批量选择，翻页清空；下架确认和逐项成功/跳过/失败结果清晰。
5. 每页数量与返回上下文符合确认选择；空态与请求失败区分。
6. 删除按钮按当前实现边界确认并执行；活动媒体任务及不可删除状态有明确反馈，删除后列表与首页运营配置不保留失效短剧 ID；排序值仍在编辑页修改。

B-03 的策略、排序及编辑范围已回填。继续回填 B-04 集数口径、B-06/B-07 审核发布可用性及 B-10 统计内容；本页六项关键选择无需重复询问。
