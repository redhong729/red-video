# B-07 发布预览与校验

> 2026-11-19 用户变更：取消送审和审核阻断；必填资料缺失时不能上架，其他事项仅提醒，上架时二次确认。以下涉及审核通过的早期要求不再适用，版本隔离、媒体检查及明确选择范围仍有效。

版本：v1.0 基础逻辑确认版  
日期：2026-11-18  
状态：本地必填校验、提醒、上架确认和下架已实现；观看资格模拟、真实解锁及统计仍待后续阶段。

## 1. 页面目的与已有基础

在明确本次目标版本的前提下，预览观看效果，查看发布阻断和提醒，选择可发布的目标，执行人工发布及查看结果。

继承 B-02～B-06 已确认规则：英文标题/简介、封面、一个分类、总集数与有效积分/试看配置；允许连载；新集默认下架；线上版本和修改稿分开；单集覆盖优先；试看不自动扣费；手动恢复不自动恢复所有下架分集；预览不产生真实交易或业务统计。

本页定义校验与交接要求，不创造审批权限、自动通过或真实积分启用决策。

## 3. 发布目标与依赖

| 场景 | 需要明确的目标 |
| --- | --- |
| 首次发布 | 待公开的剧目版本、拟上架分集及对应媒体/审核结果 |
| 连载追加 | 当前有效剧目版本与新增拟上架分集，不要求整剧计划集数全部传完 |
| 修改稿生效 | 哪个剧目或分集修改稿替换哪个线上版本，以及受价格/试看等共享改动影响的公开分集 |
| 恢复上架 | 明确恢复整剧及拟恢复的合格分集，不自动全选全部下架分集 |

每个结果对应所选版本，不混用另一版本的资料、价格、媒体状态或审核结论。未选择的无关草稿可保持不完整；如果本次目标不含剧级修改，则按当前有效剧级版本校验，不能暗中套用未发布的新策略。

共享价格、免费范围或试看改动影响多个已公开分集时，相关依赖属于本次校验范围，不能作为“无关草稿”跳过。相应依赖未通过会阻断该项共享改动；部分发布仅针对不破坏共享一致性的独立目标。

## 4. 校验报告

| 项目 | 阻断方向与边界 |
| --- | --- |
| 英文标题/简介 | 本次拟生效的剧级资料必须具备英文必备字段，其他语言按已确认后端回退 |
| 封面 | 必须有符合当前发布要求的封面；剧封面和分集封面要求不能混用，图片规格后续落实 |
| 分类 | 剧目须关联一个分类；分类停用/历史关联的具体准入规则待 B-08 统一 |
| 总集数与集号 | 总集数为正整数，不低于已有最大集号；同剧集号唯一且拟发布目标有效，不要求全部计划集上传 |
| 积分配置 | 默认免费/按集积分及单集覆盖有效，前 N 集按集号判断，不把显示排序当免费范围 |
| 试看配置 | 跟随/覆盖/关闭明确；对实际适用的付费试看，正数时长短于正片；不能用旧资源冒充新配置的试看结果 |
| 媒体 | 目标版本的实际播放资源就绪，必要检测/转码和适用资源结果有效；上传成功或文件存在不等于就绪 |
| 审核 | 本次发布对象和版本必须有有效通过结果；缺失、未通过或只有旧版本通过不能当作本次通过 |
| 可公开分集 | 首次/恢复等需要对外提供观看的场景须至少有一个合格拟上架或既有公开分集，不能公开空剧目 |
| 关联影响 | 受共享改动影响的公开内容与新配置保持一致，不以局部发布绕过共享阻断 |

校验报告显示对象、版本、通过/阻断/提醒、原因与定位入口。阻断项明确哪些目标不能发布，并可转到资料、分集、媒体或审核页面处理后重新检查。

提醒不阻断：演员/标签未填、计划集数尚未全部上传。可展示相关定时下架计划等上下文，但不因发布自动修改或取消已有计划，任务冲突规则仍留定时逻辑。

数值边界、图片规格等常规参数按相应字段/媒体方案落实；不能在未明确分类策略等依赖时擅自扩大全局阻断范围。

## 5. 部分发布与恢复

- 整剧共享条件先满足；若只有部分独立分集未就绪，列出合格项、排除项和原因，让运营明确确认本次实际发布范围。
- 不静默丢弃失败目标，也不把存在任何分集草稿理解为整剧都不能发布；连载无需等齐全部计划集。
- 共享剧级改动未通过时，不以排除某个受影响分集为手段直接让该共享配置上线。独立目标可否继续按原有效剧级版本发布，应在报告中说明使用哪个版本。
- 手动整剧下架保留原分集状态；恢复时校验拟恢复版本与合格分集，原已下架分集不自动全部恢复。
- 若所有分集都已下架，恢复需运营明确选定合格分集作为本次上架目标并校验整剧；不得默认把所有分集恢复，也不能因单集处理成功自动恢复整剧。
- 具体跨页或单页的恢复操作设计可后续落实，但必须明确本次是否恢复整剧、哪些分集上架，避免状态依赖造成无法恢复或误公开。

## 6. 版本、语言与观看资格预览

- 选择当前线上或本次候选稿，明确标识版本，首次发布没有线上版时不显示虚构数据。
- 按已启用语言预览 UI 和后端业务字段，剧名/简介缺译回退英文；不伪造未维护的内容翻译。
- 按当前所选版本计算价格、免费范围、单集覆盖和试看秒数，模拟未解锁或有效已解锁资格；免费分集按免费规则完整播放。
- 普通未解锁付费预览按适用秒数停止并提示；有效已解锁可完整播放。审核工作台的完整授权审阅与普通观看资格模拟分开。
- 预览不真实扣分、不增加积分、不创建真实观看权益，不计播放/解锁/完播业务统计。
- 真正交易启用尚未决定，模拟不能作为真实扣费、账户或跨设备权益已经验收的证据。
- 媒体或语言失败时明确对应版本和资源状态，不以正常预览假象掩盖失败。

## 7. 发布执行与结果约束

以下是保证已确认版本与校验规则成立的执行约束，不额外确定审批链或部署实现：

1. 页面预检查不代替实际提交时的最新检查；发布时再次确认目标版本、当前上下架状态、关联媒体、有效审核结果和配置。
2. 目标已被修改、取消、重新提交或下架导致结果失效时，说明变化并重新校验，不能靠过期报告绕过当前限制。
3. 重复点击、重试或重复提交不应造成重复发布副作用；具体防重复机制由后端设计。
4. 对独立目标逐项展示成功、跳过和失败，说明实际生效版本；共享变更及依赖保持一致，不以部分成功破坏线上价格/试看与资源对应。
5. 修改稿仅在发布生效后替换当前线上，失败不得误报已替换，旧线上及已开始观看继续受既有保护。
6. 发布成功不自动扣积分、改历史有效权益或取消定时下架。批量结果和变更记录可追查，具体日志保留由技术方案确定。

## 8. 保留事项

完整审核流转的送审、审批角色/多级、退回/撤回/重提/改判、结果有效性来源及权限，仍需对应流程确定。缺失依赖时不能默认通过或默认所有管理人员可发布。

真实积分解锁启用、积分来源与支付/退款、统计公式、定时执行冲突、发布回滚和旧资源回收继续留对应页面或技术设计。本页配置检查通过不等于付费业务已可正式启用。

## 9. 验收方向

1. 对象/版本及关联影响明确，旧媒体或旧审核结论不能批准新稿，无关未就绪草稿不误挡独立发布。
2. 必备资料、数量、积分/试看、媒体和审核阻断正确；演员/标签空和连载未齐仅提醒。
3. 独立目标可在明确确认后部分发布，共享阻断不能通过排除依赖绕过。
4. 恢复明确整剧与目标分集，不自动全量恢复或依处理完成自动公开。
5. 线上/候选、语言及资格预览对应真实配置，预览无真实交易与业务统计副作用。
6. 实际发布复核最新状态，重复请求不重复生效；逐项结果、原线上保留与新生效版本清晰。

本地版本绑定、媒体/配置校验、人工上架与恢复已实现并测试；观看资格模拟、多人审批和真实交易仍未实现。
