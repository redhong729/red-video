## 1. 页面目的与公共边界

从 B-02 或 B-03 进入，维护当前剧目的分集标题、媒体、免费/积分、试看及上下架，支持连载和批量操作。

沿用 [公共规则](../../08-first-release-business-rules.md) 与 [B-03](03-drama-editor.md)：一剧多集、总集数不低于已有最大集号；单集显式计费覆盖优先、未覆盖跟随剧级；已有有效解锁不重复或补扣；下架不主动中断已有观看，因下架失败的当次积分操作不扣分并提示。

本页只明确配置及操作边界，不默认启用真实积分解锁，不展开审核角色、转码参数、统计公式或定时任务执行机制。

## 3. 集号、顺序与标题

- 集号是同一剧目内唯一的正整数；总集数不足以容纳新集号时，先到 B-03 调整总集数。
- 列表按集号升序展示，不提供手动拖拽调整；前 N 集免费按集号 1～N 判断。
- 自定义标题可不填，后端按请求语言提供默认标题；有自定义内容时遵守内容语言规则，不由前端临时翻译业务文本。
- 已发布集号纠错、替换错误素材的具体约束在媒体及发布流程中补齐。

## 4. 集数口径与分集列表

| 数量 | 口径 |
| --- | --- |
| 总集数 | 剧目计划数，不代表已上传或可播数量 |
| 已上传集数 | 文件上传成功的不同分集数，包含待审核、转码中的分集，重传不重复计 |
| 已上架集数 | 单集状态为上架的数量；手动整剧下架不把子状态全部改掉，也不清零该数量 |
| 当前可播 | 另外检查整剧已上架、分集已上架、审核及媒体可用、观看资格；不与已上架状态计数混用 |

整剧下架后已上架分集数量仍可大于 0，后台需结合整剧状态表达不可新观看，不能误导为仍对外提供播放。

建议分集列表字段如下；字段存在和业务含义来自已确认范围，列宽、组合及展开方式在设计阶段确定。

| 字段 | 含义 |
| --- | --- |
| 集号、标题 | 稳定定位分集，按集号升序排列 |
| 封面、时长 | 列表展示分集封面及当前资源实际时长；未接入媒体时如实显示空状态，时长建议从媒体探测获取 |
| 上传、转码、审核状态 | 分开显示处理进度与结果，状态枚举及错误详情由 B-05/B-06 定义 |
| 上下架状态及未发布修改 | 当前生效状态与修改稿提示，不把修改稿当作已替换线上 |
| 计费来源与生效积分 | 跟随剧级 / 显式免费 / 显式积分，分别显示来源和生效结果 |
| 试看 | 跟随/覆盖/关闭及实际秒数，免费或已有有效权益完整播放 |
| 定时下架与操作 | 已设计划摘要，以及配置、预览、上传/替换、截帧、重试、上下架等入口 |

顶部显示当前剧目的剧名和状态、数量概况，提供返回剧目列表、编辑资料、批量上传及发布预览入口。进入媒体任务时保留剧目/分集上下文，失败项可定位。

## 5. 积分继承与试看

### 5.1 价格

单集显式免费/指定积分价优先；未配置覆盖则跟随剧级默认。剧级按集积分的前 N 集免费以集号判断。取消覆盖恢复跟随，已有有效解锁不重复或补扣。

### 5.2 试看

- 剧级默认 30 秒，0 表示关闭；每集可跟随、显式设置秒数或显式关闭。
- 单集显式 0 是关闭，不是“未配置”，不能错误回退成剧级 30 秒。
- 对需要解锁且尚无有效权益的付费集，启用试看时可观看正片开头 X 秒，到点停止并提示解锁，不自动扣积分。
- 免费集及有效已解锁内容完整播放，不受试看秒数截断。
- 对实际适用的付费试看，正数秒数必须短于完整时长；资源未就绪或参数无效时发布前提示调整，不能以超出时长的配置把整集作为试看放出。
- 不要求运营上传另一份试看视频。后续媒体方案可生成受限试看资源或提供等效限制，不能只依赖播放器暂停而把完整付费资源向无权益访问公开。

改剧级或单集试看配置都遵守版本生效规则。具体试看页面提示、再次试看、解锁按钮和真实交易阶段，在观看页继续细化。

## 6. 新增、修改与生效

| 场景 | 规则 |
| --- | --- |
| 新上传分集 | 默认下架，完成审核、转码及发布校验后人工上架；上传成功不自动公开 |
| 追加连载 | 整剧已上架时可继续追加合格分集，不要求先将整剧下架 |
| 修改已上架分集 | 标题、价格、试看、视频等修改存待发布稿，线上版本继续服务；按发布流程生效后替换 |
| 审核中的提交内容 | 只读，退回/撤回/重提流转留审核页 |
| 已开始观看 | 不因版本替换强制切换正在看的资源；新观看使用当前生效规则 |

保存配置不等于发布，不自动扣积分。旧资源保留多久、替换失败恢复、修改稿如何进入审核等在媒体与发布流程确定；本页不要求所有历史媒体永久复制保存。

## 7. 手动上下架与批量操作

- 单集上架需要逐项通过当前版本的审核/转码与发布条件，不绕过整剧对新观看的限制。
- 当前页可选择分集批量上架、批量下架；翻页清空选择，提交前明确对象与影响。
- 执行时按最新状态逐集校验，结果分别说明成功、跳过、失败；部分成功不误报全部成功，不能重复覆盖已成功项。
- 定时下架逐集配置，首期不提供批量改价格、批量改试看或跨页批量。
- 当前页批量上架是分集层能力，B-02 剧目列表仍只有批量下架，两层范围不互相扩张。
- 下架不强制中断已有观看，新打开提示下架；因下架失败的当次积分操作不扣分并提示。

## 8. 整剧与分集状态联动

1. 手动下架整剧，不逐个重置原有分集上架标记；保留分集状态计数，但禁止新的公开观看。
2. 对已上架整剧，当最后一个已上架分集也下架时，整剧自动转已下架。未发布的新建草稿不因没有上架分集自动变为已下架。
3. 恢复要人工上架并通过对应校验，不自动把原来已下架的分集全部恢复，也不因处理完成就重新公开整剧。
4. 整剧下架时分集如何准备上架状态、整剧恢复的操作顺序与提示，需要与 B-07 校验流程衔接，避免“恢复”绕过审核或误恢复所有集。

## 9. 定时下架

- 支持整剧与单集，入口分别在 B-02/B-04，首期逐条设置。
- 可查看、修改、取消计划；统一业务时区为北京时间 Asia/Shanghai，时间旁明确显示时区，不因中英文切换而改变实际执行时刻。
- 生效时沿用手动下架及最后一集下架的公共规则，并保护已开始观看。
- 执行误差、过期时间输入、重复计划、手动冲突、失败重试与任务审计，在定时任务逻辑补齐，不在本轮猜定。

## 10. 删除剧集（当前实现边界）

用户要求增加删除按钮；以下状态限制和级联影响是当前实现的安全边界，并非另行确认的产品决策：已上架剧集需先下架，审核中的短剧不可删除；有上传或媒体处理任务时需等待完成或取消。确认后剧集资料、关联上传媒体文件、发布/上下架记录会被永久删除；计划总集数不自动修改。

## 11. 空态、错误与验收重点

没有分集时提供批量上传入口；上传/转码/审核失败显示具体环节并进入相应任务；配置未完成或资源未就绪不可被误当作已可发布。网络失败与无数据区分，保留可恢复的上下文。

验收重点：

1. 列表按集号升序、不可拖拽调整；同剧不出现重复集号，前 N 集免费按集号判断。
2. 上传去重、分集上架状态和实际可播口径分开，整剧手动下架不清零子状态计数。
3. 默认标题按后端语言返回，自定义不被前端自动翻译。
4. 跟随/显式价格与跟随/覆盖/关闭试看都正确；0 关闭不误回退；免费/有效解锁不被试看截断。
5. 新集默认下架并手动发布；修改稿保存不替换线上，发布后新观看用新版本、既有观看不强制切换。
6. 当前页批量上下架逐项校验并分项显示结果，翻页清空选择。
7. 最后一个上架分集下架后已上架整剧自动下架；恢复不自动全量恢复分集。
8. 整剧/单集计划使用北京时间，UI 语言切换不改变执行时刻，支持查看/修改/取消。
9. 剧集删除须确认；已上架或审核锁定状态、活动媒体任务不能删除，删除后关联上传资源和记录清理，计划总集数保持原值。

这三页基础逻辑已确认；剧集条目、媒体、本地基础审核发布及手动上下架已实施。后续页面只补齐媒体任务、完整审核发布、定时执行、观看与真实交易、统计口径，不重复询问本页已确认选择。
