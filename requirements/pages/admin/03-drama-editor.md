## 1. 目的与字段范围

从 B-02 新增或编辑进入，维护标题、封面、简介、一个分类、多标签、演员、总集数、付费策略和排序，支持保存草稿，并进入分集管理及发布预览。

允许连载、后台中英文 UI、前端请求当前语言并展示后端业务数据等公共规则不变。

## 2. 已确认选择

| 编号 | 用户选择 |
| --- | --- |
| EDIT-Q1 | 保存草稿只要求至少一个语言版本的标题，其他可后补；发布前补齐标题、封面、简介、分类、总集数和有效付费配置；演员、标签可选；分集、审核和转码的具体发布校验在发布页确定 |
| EDIT-Q2 | 发布必须有英文标题和简介；其他语言按需由后台维护，缺少当前语言时由后端回退英文；UI 语言切换与内容编辑语言分开，不自动翻译 |
| EDIT-Q3 | 剧目封面可手动上传，上传分集后也可选视频截帧替换；发布前必须有封面，尺寸与裁剪细节后续确定 |
| EDIT-Q4 | 演员可手工增删姓名，角色名可选，不另建演员库 |

| EDIT-Q6 | 人工排序默认 0，非负整数，数值越大优先级越高，到本页修改；后台列表仍按更新时间，前台哪些页面采用此排序后续确定 |
| EDIT-Q7 | 剧级支持“默认免费”和“按集积分”，后者可设前 N 集免费、其余统一积分价，N=0 可无默认免费集；以集号 1～N 判断 |

## 3. 草稿与发布资料要求

| 字段 | 保存草稿 | 发布前要求 | 待细化 |
| --- | --- | --- | --- |
| 标题 | 至少一个语言版本有标题 | 英文版本必备 | 字数及重名提示 |
| 简介 | 可后补 | 英文版本必备 | 字数和格式 |
| 封面 | 可后补 | 必须有封面 | 图片尺寸、大小及裁剪 |
| 分类 | 可后补 | 必须选一个分类 | 分类失效与新建入口 |
| 标签 | 可不填 | 可选，多标签 | 选择、数量及停用处理 |
| 演员 | 可不填 | 可选，姓名列表及可选角色名 | 字数、重复与展示细节 |
| 总集数 | 可后补 | 正整数，不低于现有最大集号，可增减 | 与 B-04 集号及数量口径回填 |
| 付费策略 | 可后补 | 默认免费或有效按集积分配置 | 单集及试看按 B-04 回填，真实交易阶段另定 |
| 默认试看 | 默认 30 秒，可设 0 关闭 | 对实际适用的付费试看校验时长 | 单集可跟随/覆盖/关闭，规则已在 B-04 确认 |
| 排序 | 默认 0 | 非负整数，大值优先 | 同值顺序及前台使用位置另定 |

草稿可暂时只有非英文标题，但不能在缺少英文必备资料时通过发布资料检查。保存草稿不代表自动审核通过或上架，也不要求先上传完整总集数。

## 4. 内容语言

- 内容字段编辑语言独立于后台 UI 语言，切换后台中英文不会自动改变或翻译正在编辑的内容。
- 本页英文标题、简介是发布必备资料；其他语言版本由运营按需维护。
- 观众请求对应语言时，后端对本页字段返回该语言数据，缺失时回退英文；前端直接展示结果。
- 语言切换保留未保存输入已确认；逐字段语言回退和删除语言版本等特殊规则后续补齐，不能因此清空其他语言的编辑内容。
- 分类、标签也由后端提供语言数据，但其维护页的发布必备语言和逐字段回退规则还需单独统一，不以本轮选择认定所有分类标签已具备英文翻译。

## 5. 封面

本地已支持新建短剧时预上传封面并在保存草稿时自动关联，也支持保存后直接上传或更换 JPG、PNG、WebP 图片（最大 10 MiB，宽高均不超过 8192 像素）；已有分集时可在剧集行的封面窗口选择截帧并明确确认设为剧目封面。封面来源不影响“发布必须已有封面”的要求。

截帧来源、素材处理失败、替换确认、裁剪、格式与尺寸在媒体/页面设计时细化。本轮不假设系统自动替运营选择封面，也不要求创建草稿前先有视频。

## 6. 演员、总集数与排序

- 演员是可选的手工姓名列表，支持增删，角色名可选，不新增独立演员库。
- 总集数发布前为正整数，可随连载增加或减少，但不能小于现有分集最大集号；超出计划先改总集数，再新增对应集号。
- “最大集号”不是当前已上传文件数量，也不是分集显示排序值，需与 B-04 的集号规则一致。
- 人工排序默认 0，只接受非负整数，大值代表更高优先级；后台列表依旧更新时间倒序。
- 哪些前台列表使用该排序值及同值处理，在前台页面确定，不把本页选择自动应用到所有前台结果。

## 7. 已确认积分配置

| 项目 | 规则 | 说明 |
| --- | --- | --- |
| 默认免费 | 跟随本策略的分集免费 | 单集显式覆盖仍优先，不能误标整剧一定全部免费 |
| 按集积分 | 前 N 集默认免费，其余跟随剧级统一积分价，N=0 可全为默认付费 | 以集号判断 |
| 单集覆盖 | 单集显式免费/指定积分价优先；没有覆盖则跟随剧级 | 取消覆盖恢复跟随，不把默认值永久复制到每集 |
| 策略变更 | 只影响跟随分集与未来新解锁，已有有效解锁不重复或补扣 | 已上架剧级策略改动随修改稿发布生效，不在保存时直接改变线上规则 |

常规校验建议：N 为 0 到总集数之间的整数，付费积分价为正整数；总集数变更使 N 失效时需调整配置。草稿允许未补完整策略，发布前必须通过配置校验；本轮未决定真实积分解锁的启用阶段，也不加入整剧一次性解锁。

关联 B-04 已确认默认试看 30 秒，可设 0 关闭，单集可覆盖。未解锁付费集只试看正片开头对应秒数，到点提示解锁不自动扣分；免费和有效已解锁播放完整内容。适用的试看必须短于完整时长，发布前校验。剧级默认试看改动同样随修改稿发布生效。

## 8. 编辑状态与生效

| 情况 | 编辑与保存行为 |
| --- | --- |
| 新增/草稿 | 可编辑，至少一种语言标题即可存草稿，不自动上架 |
| 审核中的已提交内容 | 只读，如何退回、撤回和重新提交由审核页定义 |
| 已上架剧目 | 线上版本继续服务，修改存为待发布稿；经对应发布流程生效后替换 |
| 已下架剧目 | 可编辑，保存不自动重新上架 |

已上架存在修改稿时，主状态仍为“已上架”，附加“有未发布修改”标识；若修改稿进入审核，其处理进度单独展示，不把仍在线的整剧误判为已下架或仅审核中。具体审核流转不在本页提前确定。

剧级策略也遵守版本生效规则。B-04 已确认：新集默认下架，校验后手动上架；单集标题、价格、试看和视频的修改稿发布后替换线上，已有观看不强制切换。旧媒体保留、替换失败等任务细节留 B-05/B-07，不自动要求所有历史媒体永久复制。

## 9. 保存、跳转与未保存修改

- 手动保存后留在当前页；“保存并管理分集”保存成功后携带剧目进入 B-04，保存失败不跳转。
- 切换后台 UI 语言或内容编辑语言时保留尚未保存的输入，不能依靠切换触发自动翻译或丢弃资料。
- 有未保存修改时离开页面，提供保存或放弃的提示；保存不自动上架、下架或扣积分。
- 上传与截帧任务的处理状态不等于表单已经保存，媒体入口和失败处理随 B-05 细化。

建议 B-02 已上架行优先展示线上生效的资料，待发布修改通过标识和编辑稿查看；运营更新时间与正式生效时间的具体展示在页面设计与关联回填时统一。

## 10. 验收与关联回填

完整审核流转在 B-06/B-07，统计口径在 B-10，真实解锁启用阶段在观看和交易范围决策时处理。

1. 任一语言至少有标题可保存草稿，缺其他发布资料不会阻止该草稿保存。
2. 缺英文标题或简介不能通过发布资料校验；其他必备字段亦须齐全。
3. 演员和标签可空，不错误阻断发布。
4. 切换后台 UI 语言不改写内容字段；后端按请求语言供给剧名/简介，缺译回退英文。
5. 上传图片和分集截帧都可作为剧封面来源，发布前检查封面存在。
6. 演员可不填，也可维护多名姓名和可选角色名，不要求先创建演员库资料。
7. 总集数变更不能小于现有最大集号；排序默认 0、非负且在编辑页修改，不改变后台默认排序。
8. 前 N 集免费按集号判断；单集覆盖与跟随能够区分，剧级变更不改变显式覆盖及已有有效解锁。
9. 已上架内容保存修改稿不改变线上资料和策略；发布生效后才替换，主状态保持已上架并有修改标识。
10. 审核中的提交内容只读；保存并管理分集只在保存成功后跳转，语言切换和离开时不误丢输入。
11. 剧级试看默认 30 秒可关闭，单集显式 0 不误回退；免费/有效解锁完整播放，试看结束不自动扣积分。

具体操作步骤随本页其他规则确定后补齐，不代表已运行测试。
