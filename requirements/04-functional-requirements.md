# 功能需求

版本：v0.5  
状态：功能范围与已确认规则更新至本轮；标记为“建议/待细化”的内容未冻结。

## 1. 后台功能

| 编号 | 功能 | 已确认范围及待细化边界 | 来源 |
| --- | --- | --- | --- |
| A-01 | 后台访问 | 登录和退出作为管理基础；账号与权限细则待定 | U-01 |
| A-02 | 剧目资料 | 标题、封面、简介、分类、标签、演员、总集数、付费策略、排序；可存草稿；列表提供有状态限制的永久删除 | U-13；2026-11-23 |
| A-03 | 分集管理 | 多集连载、批量上传、按集号排序、时长、免费/积分、试看、单集上下架；列表提供有状态限制的永久删除 | U-05、U-10、U-14；2026-11-23 |
| A-04 | 分类与标签 | 每剧一个分类、多标签；后台维护与业务语言数据 | U-12、U-17；维护细节待定 |
| A-05 | 发布与下架 | 仅上下架；分集当前页批量上/下架，剧目列表只批量下架；末集下架联动已上架整剧下架，已有观看不中断 | U-10、U-11；B-02/B-04 已确认 |
| A-06 | 预览与查询 | 四状态查询；发布校验本次版本及关联影响，阻断/提醒分开，合格独立目标可明确部分发布；版本/语言/资格预览无真实交易与统计 | U-13、U-15；B-02/B-07 已确认 |
| A-07 | 后台双语 UI | 中英文菜单、组件与业务提示；操作上下文保留规则待细化 | U-09 |
| A-08 | 审核工作台与流程 | 对象版本平铺、线上对比、完整授权预览、定位意见及通过/未通过留痕；完整审批角色和流转仍待定 | U-13、U-14；B-06 页面/记录已确认 |
| A-09 | 媒体任务 | MP4/50个/1GB、映射冲突、自动处理、最高1080p单版本、候选/手动截帧、续传、失败阶段有限重试和批次受控取消 | U-14；B-05 已确认 |
| A-10 | 定时下架 | 整剧/单集均支持，逐条设置，可查看/修改/取消，北京时间明确标注；执行与冲突待细化 | U-10；B-04 已确认 |
| A-11 | 视频统计 | 播放量、解锁量、完播率等；建议支持剧目和分集维度，指标口径待定 | U-15 |
| A-12 | 内容语言供给 | 后端按前端当前语言提供业务数据；翻译来源、维护入口及回退待定 | U-17 |

B-07 已收敛可公开分集、同版本有效审核通过和媒体就绪等阻断要求。允许连载，不以总集数全部上传为前提；演员/标签未填和计划未齐仅提醒。上传、审核、转码和生命周期分开，审批有效来源及权限仍需完整流转定义。
