### 2.1 公共交互

- 语言切换：翻译 UI，并携带新语言重新取得业务展示数据。
- 主屏幕入口引导：由 W-09「我的」页提供；安装图标按当前界面语言打开首页。
- 加载中、空态、失败提示：按所在页面上下文显示；局部列表失败不默认替换整个页面。
- 积分不足、登录后解锁、积分购买等入口仅在对应交易阶段启用后细化；本清单不默认首期增加账户、钱包和充值页。

## 3. 状态与异常覆盖

| 情形 | 覆盖位置 | 期望方向 |
| --- | --- | --- |
| 首次加载、继续加载 | 列表、分类、结果、详情、任务及统计 | 清晰的加载反馈，不误判为空 |
| 平台暂无可展示短剧 | 首页 | 内容空态及可用导航 |
| 分类下无内容、筛选无结果、搜索无命中 | 分类/结果 | 区分原因，允许修改关键词或条件 |
| 无分集、尚未上传完成 | 后台详情/上传任务 | 展示准备进度；不作为可播放内容发布 |
| 上传、转码、审核失败 | 后台任务/审核/发布校验 | 说明失败环节、保留成功项，按权限重试或重提 |
| 整剧或单集下架 | 直达详情、播放或旧入口 | 提示已下架；因下架失败的当次积分操作不扣分 |
| 下架时已经开始观看 | 播放页 | 不主动打断当前观看；具体会话边界待细化 |
| 地址或内容不存在 | W-07 | 明确与下架区分，提供返回入口 |
| 网络异常、接口失败 | 全站按上下文 | 保留可恢复的操作上下文，提供重试 |
| 视频无法加载或播放 | W-06 | 播放错误及重试/返回分集入口 |
| 接口业务字段缺少对应语言 | 列表、详情、分类/标签 | 采用后端确定的回退结果；前端不自行生成译文 |
| 未登录、积分不足、试看结束 | 交易能力启用后的观看场景 | 明示下一步；不默认自动扣分或自动购买 |
| 无统计数据或指标未启用 | B-10 | 区分真实零值、暂无数据和未启用 |

空态是各页面的状态，不为每一种空态单独新增一个路由。具体文案、视觉样式及按钮动作后续逐页定义。

## 4. 页面之间的主要路径

后台：B-01 登录 → B-02 剧目列表 → B-03 建剧/草稿 → B-04 分集管理 → B-05 上传与处理 → B-07 校验/二次确认/上架 → B-02/B-04 下架管理。B-10 统计尚未实现；B-06 审核步骤已取消。

媒体转码与发布校验分别反馈；发布操作复核当前版本和状态后直接生效，不再经过送审。

前台：W-01 首页 → W-02 分类或 W-03 搜索 → W-04 结果 → W-05 详情 → W-06 播放；任一位置根据情况进入局部空态、错误状态或 W-07 异常页。

## 5. 下一阶段逐页细化顺序

1. B-02、B-03、B-04：先确定剧目、分集、付费配置和状态的含义。
2. B-05、B-07：补齐批量上传、媒体处理与直接发布校验；B-06 仅保留历史记录兼容。
3. W-01～W-06：补齐首页、分类、搜索、结果、详情和观看体验。
4. 下架、定时任务、异常与空态：检查跨页面规则，尤其当前观看与新打开、扣分失败的区别。
5. B-08～B-10、语言数据与主屏幕入口：补齐维护与统计口径，并回查上述页面。

B-01 和后台中英文作为公共访问基础同步细化。每页后续统一记录：目的、进入与离开路径、字段、操作、状态、校验、异常、权限、语言和验收；本轮不展开字段级交互。
