## 2. 积分配置与实际交易分开确定

后台的剧级付费策略、分集积分价格、试看及付费配置校验已经进入本轮内容管理范围，不能再统一视作后期占位功能。

真实积分扣费和权益解锁是否随首期启用尚未明确；原先积分购买、真实支付与广告后期考虑的方向保留。建议先打通内容运营及免费内容免登录观看，再确定交易阶段。这里是实施分期建议，不认定用户要求所有分集免费，也不默认首期必须真实收款。

| 能力 | 规划边界 |
| --- | --- |
| 付费内容配置 | 当前纳入后台页面与发布校验规划 |
| 真实扣积分与观看权益 | 阶段待确认；启用前补账户归属、积分来源、重复解锁和失败回退 |
| 购买积分与支付 | 后期方向保留，币种、套餐、渠道及退款另行规划 |
| 解锁数据统计 | 当前纳入指标规划；没有真实解锁时如实显示未启用，不虚构指标 |
| 广告联盟 | 后期方向保留，不默认采用观看广告解锁 |

## 3. 优先细化顺序建议

1. 剧目、分集、状态与付费配置的含义。
2. 批量上传、审核转码、预览校验、连载发布。
3. 首页到播放的页面逻辑、语言数据与模糊搜索。
4. 手动/定时下架、当前观看保护、积分失败、空态异常。
5. 分类标签维护与统计口径，回查完整闭环。

## 4. 尚未纳入的扩展

原生 App、应用商店、小程序、离线下载、消息推送、评论社交、个性化推荐、会员订阅、分销、多租户及创作者入驻尚无确认需求。独立演员库、自动翻译及字幕制作也不因本轮字段扩充而自动纳入。
